# 深度学习基础

## 感知机与神经网络

感知机是最简单的神经元模型，也是理解神经网络的第一块积木。

### 感知机原理

感知机对输入做加权求和，经过阶跃函数输出：

```text
y = step(w1*x1 + w2*x2 + ... + wn*xn + b)
```

- 权重 w 表示每个输入的重要程度。
- 偏置 b 是决策边界的平移量。
- 输出 0/1 代表分类结果。

感知机训练时，根据预测错误调整权重，本质是在找一条能把数据分开的直线。但**单层感知机只能解决线性可分问题**（如 AND、OR），无法处理异或（XOR）这类线性不可分问题——这是感知机当年的致命局限。

### 从感知机到神经网络

把大量"神经元"分层堆叠，就构成神经网络：

- **输入层**：接收原始特征。
- **隐藏层**：逐层提取更高阶的特征。
- **输出层**：输出预测结果。

多层结构让网络能拟合任意复杂函数（万能近似定理），解决了单层感知机的局限。

### 训练三要素

1. **前向传播**：输入经过各层计算得到预测。
2. **损失函数**：衡量预测和真实的差距（如交叉熵、均方误差）。
3. **反向传播 + 梯度下降**：从输出层往前逐层计算梯度，用链式法则把误差传到每一层，更新权重。

### 反向传播的直觉

反向传播（backpropagation）利用**链式法则**：输出层的误差依赖于每个中间层的输出，可以逐层反推每个权重对最终误差的"责任"，然后按梯度方向更新。深度学习的训练本质就是"求梯度 + 梯度下降"的大规模工程。

### 一个简单的多层感知机

```python
import torch
import torch.nn as nn

model = nn.Sequential(
    nn.Linear(784, 128),   # 输入 784 维（如 28x28 图像），隐藏层 128
    nn.ReLU(),
    nn.Linear(128, 10),    # 输出 10 类
)

loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
```

## 激活函数

激活函数给神经网络引入**非线性**。如果没有激活函数，多层线性变换等价于单层线性变换，网络"白深了"——这是激活函数存在的根本原因。

### 常用激活函数对比

| 函数 | 公式 | 输出范围 | 特点 |
|---|---|---|---|
| ReLU | max(0, x) | [0, +∞) | 计算快、缓解梯度消失，最常用 |
| Sigmoid | 1/(1+e^-x) | (0, 1) | 适合二分类输出层；深层网络会梯度消失 |
| Tanh | (e^x-e^-x)/(e^x+e^-x) | (-1, 1) | 零中心，优于 Sigmoid，但仍有饱和问题 |
| LeakyReLU | x if x>0 else 0.01x | 全实数 | 避免 ReLU 神经元死亡 |
| Softmax | 归一化指数 | (0,1) 和为 1 | 多分类输出层专用 |

### 为什么 ReLU 最常用

- 计算极快（一次比较）。
- 正区间梯度恒为 1，缓解梯度消失。
- 天然稀疏激活（负值直接置 0）。

### ReLU 的缺点：神经元死亡

如果某个神经元对所有输入都输出负值，梯度为 0，权重再也不更新，这个神经元就"死"了。解决办法：LeakyReLU、PReLU、或者小学习率。

### 梯度消失与梯度爆炸

深层网络中梯度连乘，值会指数级缩小（消失）或放大（爆炸）：

- **梯度消失**：深层网络几乎学不动 → 用 ReLU 等非饱和激活函数、BatchNorm、残差连接解决。
- **梯度爆炸**：训练发散 → 用梯度裁剪（gradient clipping）限制梯度范数。

## 卷积神经网络 CNN

CNN 擅长处理图像，核心思想是**局部感受野 + 权值共享**，用比全连接少得多的参数捕获空间特征。

### 卷积层

卷积核（filter）在图像上滑动，逐位置做加权求和，提取局部特征：

- 早期层提取**低级特征**：边缘、颜色、纹理。
- 深层提取**高级特征**：眼睛、车轮、语义部件。

```python
conv = nn.Conv2d(in_channels=3, out_channels=32, kernel_size=3, padding=1)
```

- `in_channels`：输入通道数（RGB 图像是 3）。
- `out_channels`：卷积核数量，即输出特征图个数。
- `stride`：滑动步长，控制特征图尺寸。
- `padding`：边缘补零，保持尺寸。

### 池化层

池化做降采样，减少计算量、增强平移不变性：

- **最大池化（MaxPooling）**：取窗口内最大值，保留最显著特征，最常用。
- **平均池化（AveragePooling）**：取窗口平均值，更平滑。

```python
pool = nn.MaxPool2d(kernel_size=2, stride=2)  # 尺寸减半
```

### 经典 CNN 结构

```
输入 → [卷积 + 激活 + 池化] × N → 展平 → 全连接 → Softmax 分类
```

### 经典网络

- **LeNet-5**（1998）：第一个成功的 CNN，用于手写数字识别。
- **AlexNet**（2012）：深度学习爆发起点，用了 ReLU、Dropout、GPU 并行。
- **VGG**：用统一的小卷积核堆深网络。
- **ResNet**（2015）：提出**残差连接**解决深层网络退化问题。

### ResNet 为什么有效

ResNet 让网络学习"残差"而不是"完整映射"：`输出 = F(x) + x`。恒等映射（x → x）通过短路连接直接传递，梯度可以无损穿过网络，让几百层的网络也能训练。

```python
class ResidualBlock(nn.Module):
    def __init__(self, in_c, out_c):
        super().__init__()
        self.conv1 = nn.Conv2d(in_c, out_c, 3, padding=1)
        self.bn1 = nn.BatchNorm2d(out_c)
        self.relu = nn.ReLU()
        self.conv2 = nn.Conv2d(out_c, out_c, 3, padding=1)
        self.bn2 = nn.BatchNorm2d(out_c)

    def forward(self, x):
        identity = x
        out = self.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return self.relu(out + identity)   # 残差连接
```

## 训练技巧与过拟合缓解

### Dropout

训练时随机"关闭"一部分神经元，防止网络过度依赖某些特征：

```python
dropout = nn.Dropout(p=0.5)  # 训练时 50% 神经元随机失活
```

原理：每次训练用不同的"子网络"，相当于对多个模型做集成，测试时全部激活。

### Batch Normalization

对每一层输出做归一化，稳定数据分布：

- 允许更大的学习率，加速收敛。
- 缓解内部协变量偏移。
- 有轻微正则化效果。

### 数据增强

通过变换扩充训练数据，让模型见过更多变体：

```python
from torchvision import transforms

augment = transforms.Compose([
    transforms.RandomHorizontalFlip(),   # 随机水平翻转
    transforms.RandomRotation(10),       # 随机旋转
    transforms.ColorJitter(0.2, 0.2, 0.2),  # 随机颜色抖动
    transforms.ToTensor(),
])
```

### 早停（Early Stopping）

监控验证集指标，连续 N 轮不提升就停止训练，防止过拟合。

### 学习率策略

- **学习率衰减**：训练后期降低学习率，精细收敛。
- **预热（warmup）**：训练初期小学习率，稳定后调大。
- **warmup + cosine decay**：现代训练的标准配置。

## 训练调试经验

1. **先过拟合一个 batch**：模型能记住一个 batch 说明代码流程通，否则先查代码 bug。
2. **损失不降排查**：检查学习率（太大震荡、太小不动）、数据归一化、梯度是否正确。
3. **观察中间输出**：可视化卷积核、特征图、权重分布。
4. **记录实验**：每次实验记下超参数、数据、结果，别靠记忆。

## 深度学习与机器学习的关系

- **机器学习**是更广的范畴：特征工程 + 模型选择，人工设计特征。
- **深度学习**是机器学习的一个分支：用多层神经网络自动学习特征表示，摆脱手工特征工程。
- 在图像、语音、自然语言等"原始数据信息量大"的场景，深度学习优势明显；在表格数据、小样本场景，传统机器学习（如 XGBoost）往往更强、更稳定。
