# 数据结构与算法

## 数组与链表

数组和链表是两种最基础的数据结构，理解它们的本质差异是后续一切数据结构的地基。

### 数组

数组是**连续内存存储**的一组同类型元素，按下标访问是 O(1)。

**优点**：
- 随机访问 O(1)：`arr[i]` 直接通过"基地址 + i × 元素大小"算出地址。
- 缓存友好：连续内存，CPU 缓存命中率高。

**缺点**：
- 插入/删除要移动元素，平均 O(n)。
- 容量固定（静态数组）或扩容要拷贝（动态数组）。

**动态数组（如 Python list）**：容量不足时按倍数扩容（通常 1.5~2 倍），均摊插入成本仍是 O(1)。

### 链表

链表通过**指针串联节点**，每个节点存数据和下一个节点的地址。

**优点**：
- 插入/删除只需改指针，O(1)（前提：已知位置）。
- 无需连续内存，按需分配。

**缺点**：
- 随机访问要遍历，O(n)。
- 每个节点有指针额外开销（空间）。
- 缓存不友好。

### 对比

| 维度 | 数组 | 链表 |
|---|---|---|
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n)（移动元素） | O(1) |
| 尾部插入 | 均摊 O(1) | O(n)（要遍历到尾部，除非有尾指针） |
| 空间 | 连续，可能浪费 | 每节点多存指针 |
| 缓存 | 友好 | 不友好 |

### 链表变体

- **双向链表**：每个节点有前驱和后继指针，两端操作都方便。
- **循环链表**：尾节点指向头节点，适合环形结构（如约瑟夫环、循环队列）。

### 常见应用

- 数组：哈希表（开放寻址）、堆、栈（连续栈）。
- 链表：LRU 缓存（哈希表 + 双向链表）、实现栈和队列、图的邻接表。

## 栈与队列

### 栈（Stack）

**后进先出（LIFO）**，只能在一端（栈顶）操作，像一摞盘子。

```python
stack = []
stack.append(1)     # push
stack.append(2)
stack.pop()         # 弹出 2
stack[-1]           # peek 栈顶
```

**经典应用**：
- 函数调用栈：递归、函数调用的返回地址管理。
- 括号匹配：`([{}])` 合法性判断。
- 表达式求值：中缀转后缀、逆波兰表达式。
- 撤销操作：编辑器 Ctrl+Z。
- 深度优先搜索（DFS）可用栈实现。

### 队列（Queue）

**先进先出（FIFO）**，从队尾进、队头出，像排队。

```python
from collections import deque

q = deque()
q.append(1)       # 队尾入队
q.append(2)
q.popleft()       # 队头出队 → 1
```

**经典应用**：
- 任务调度、消息队列。
- 广度优先搜索（BFS）。
- 缓存淘汰（FIFO 策略）、打印任务排队。

### 队列变体

- **双端队列（deque）**：两端都能进出，Python 的 `deque` 实现。
- **优先队列（Priority Queue）**：按优先级出队，用堆实现，如任务按紧急程度处理。
- **循环队列**：用数组实现队列时复用已释放的空间，避免假溢出。

## 哈希表

哈希表（字典/映射）用**哈希函数**把键映射到数组下标，实现平均 O(1) 的插入、查找、删除。

### 哈希冲突

不同键映射到同一位置就是冲突。两种主流解决方式：

1. **链地址法**：每个槽位挂一个链表（或红黑树）。Java HashMap、Python dict（近似）。
2. **开放寻址法**：冲突了往后找空位（线性探测、二次探测）。Python dict 早期版本、Redis 的 dict 用过。

### 扩容与负载因子

- 装载因子 = 元素数 / 槽位数。
- 超过阈值（如 0.75）就扩容重哈希，均摊后仍是 O(1)。

### 哈希表的应用

- 字典、集合去重。
- 缓存（Redis、LRU）。
- 计数统计（Counter）。
- 数据库索引的哈希索引。

### 工程要点

- 哈希函数要均匀、计算快。
- 不要用可变对象做键（哈希值会变，导致找不到）。
- 防攻击：恶意构造哈希碰撞的键可造成 DoS，生产用随机化哈希。

## 二叉树

二叉树是每个节点最多两个子节点的树，是堆、BST、红黑树等的基础。

### 遍历方式

```python
def inorder(root):        # 中序：左-根-右
    if not root:
        return
    inorder(root.left)
    print(root.val)
    inorder(root.right)

def preorder(root):       # 前序：根-左-右
    ...

def postorder(root):      # 后序：左-右-根
    ...

def level_order(root):    # 层序：用队列 BFS
    ...
```

- 前/中/后序是深度优先（DFS），层序是广度优先（BFS）。
- 中序遍历二叉搜索树 = 有序序列（重要性质）。

### 二叉搜索树（BST）

左子树所有节点 < 根 < 右子树所有节点。查找、插入、删除平均 O(log n)。

**退化问题**：插入有序数据时 BST 退化成链表，复杂度变 O(n)。所以有了平衡树：

- **AVL 树**：严格平衡，左右子树高度差 ≤ 1。
- **红黑树**：近似平衡，插入删除更快，用于 TreeMap、Linux 内核调度器、Java HashMap 冲突链表转红黑树。
- **B 树 / B+ 树**：多路平衡搜索树，降低树高减少磁盘 IO，是数据库和文件系统的核心索引结构。

### 堆

堆是完全二叉树，用于实现优先队列：

- **最大堆**：父节点 ≥ 子节点，堆顶是最大值。
- **最小堆**：父节点 ≤ 子节点，堆顶是最小值。

```python
import heapq

heap = []
heapq.heappush(heap, 3)
heapq.heappush(heap, 1)
heapq.heappush(heap, 2)
heapq.heappop(heap)   # 弹出最小值 1
```

堆的应用：Top-K 问题、合并 K 个有序链表、Dijkstra 最短路径、任务调度。

## 二分查找

二分查找要求数据**有序且支持随机访问**，每次取中间元素和目标比较，排除一半，时间复杂度 O(log n)。

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

### 变体与边界

- **查找左边界/右边界**（有重复元素）：找第一个/最后一个等于 target 的位置。
- **浮点数二分**：判断条件改为精度。
- **"寻找左边界"模板**：`right = mid`，注意死循环。

### 适用条件

- 数据有序。
- 支持随机访问（数组可以，链表不行——链表要用跳表）。
- 单调性：有时候判断条件不直接是大小，而是满足某个性质（"二分答案"思想）。

### 二分查找的应用

- 有序数组查找。
- 旋转数组找最小值。
- 求平方根、浮点数求根。
- "二分答案"：在值域上二分，如"木材切割的最大长度""分发巧克力的最小最大值"。

## 排序算法

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 快排 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆排 | O(n log n) | O(n log n) | O(1) | 不稳定 |

- **快排**：实际最快，分治 + 原地分区，Python 的 `sorted` 用的就是改良快排（Timsort 混合）。
- **归并**：稳定、适合外部排序（内存装不下时）、链表排序。
- **堆排**：最坏也 O(n log n)，但常数大，实际用得少。
- **工程选择**：语言内置排序（Timsort/Python、DualPivotQuicksort/Java）通常就是最优解，不要手写排序除非面试。

## 递归与回溯

递归是函数调用自身，必须要有**终止条件**，否则无限递归。回溯 = 递归 + 撤销选择，用于穷举所有可能。

```python
def permute(nums):
    result = []
    def backtrack(path, rest):
        if not rest:
            result.append(path[:])
            return
        for i, x in enumerate(rest):
            backtrack(path + [x], rest[:i] + rest[i+1:])
    backtrack([], nums)
    return result
```

**经典回溯题**：全排列、组合、子集、N 皇后、数独。

**剪枝**：提前排除不可能的分支，是回溯优化的核心（如 N 皇后按列、按对角线判断）。

## 动态规划

动态规划（DP）解决"有重叠子问题的最优子结构"问题，核心是**状态定义 + 状态转移方程 + 初始化**。

经典例子：斐波那契、爬楼梯、背包问题、最长公共子序列、编辑距离。

```python
def climb_stairs(n):
    dp = [0] * (n + 1)
    dp[0] = dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]
```

**思考步骤**：
1. 定义状态（dp[i] 表示什么）。
2. 写转移方程（dp[i] 怎么从之前的算出来）。
3. 确定初始化和边界。
4. 优化空间（滚动数组）。

## 图

- **存储**：邻接矩阵（稠密图）、邻接表（稀疏图，常用）。
- **遍历**：DFS（递归/栈）、BFS（队列，求最短路径）。
- **最短路径**：Dijkstra（非负权，O((V+E)logV)）、Bellman-Ford（负权）、Floyd（全源）。
- **拓扑排序**：有向无环图，任务依赖排序，Kahn 算法 + BFS。
- **最小生成树**：Prim、Kruskal。

## 刷题与学习方法

1. 先掌握基础数据结构（数组/链表/栈/队列/哈希/树）再上算法（排序/二分/递归/DP/图）。
2. 每个知识点记"模板 + 变体"，会套模板再谈优化。
3. 复杂度分析是基本素养：每道题先估算暴力复杂度，再想优化。
4. 用"一题多解"训练：比如 Top-K 用堆、快排分区、计数排序各写一遍。
